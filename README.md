# A.S.C. Launcher

Launcher officiel de **Project A.S.C.**

## Téléchargement

Téléchargez la dernière version du launcher dans la section **Releases** :

* **Windows** — `A.S.C. Launcher.exe`
* **Linux** — `A.S.C. Launcher`

Le launcher télécharge et se met à jour automatiquement pour jouer à **Project A.S.C.**, un serveur Minecraft extraction shooter.
